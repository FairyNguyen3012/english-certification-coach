# Frontend Rules

- Use TypeScript.
- Prefer reusable components; check `src/components/ui` and `src/components/quiz` first.
- Avoid unnecessary client components.
- Keep UI responsive; check at 375px width.
- Support light and dark mode through the tokens in `globals.css`.
- Provide loading and error states.
- Keep business logic outside presentational components (put it in `src/lib`).
